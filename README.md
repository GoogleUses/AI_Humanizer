# AI Humanizer v2
Advanced client-side AI text humanizer that disrupts the statistical patterns AI detectors (GPTZero, Turnitin, Originality.ai, Copyleaks, Winston AI) rely on.
## Features
- AI tell word elimination (removes "furthermore," "moreover," "utilize," etc.)
- Burstiness engineering (forced short punch sentences + long run-ons)
- Mid-sentence interruption injection
- Typo injection at 2% rate (strong human signal)
- Rhetorical question insertion
- First-person aside injection
- Transition word replacement
- Punctuation variation (em-dashes, semicolons)
- Paragraph restructuring
- Non-deterministic output (re-run for different results)
- Live statistics: word count, sentence count, avg length, burstiness score
