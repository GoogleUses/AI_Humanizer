# Gobattle.io Item Values

Static, build-free GitHub Pages site for GoBattle.io item values and relic upgrade points.

## Features

- Relic level, effect, and point progression
- Other items sorted from highest value to lowest
- Search and item-type filters
- Responsive layout

## Publish to GitHub Pages

Upload the contents of this folder to the root of the `GoogleUses/GB_Values` repository. In **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, and save. The site entry point is `index.html`.
